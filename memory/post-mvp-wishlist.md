# Post-MVP Wishlist

從 2026-04-26 Run #1 「不好玩」之後衍生的功能想法。**等 Run #2-3 累積數據再逐條評估解凍**，一次解凍 1 條 → playtest → 判斷是否拉回好玩 → 否則砍。

## 候選

### 1. 靈魂區 / Ragnarök
死馬不消失，進入靈魂區，最終可參加 Ragnarök 大賽。
- **解決什麼**：30 回合結束太突兀；強馬死掉感覺浪費
- **代價**：違反現有 invariant「5 歲一律從列表移除」；新狀態 + UI + 事件層
- **解凍前要看**：Run #2 玩家對死亡的情緒；是否需要終局儀式感

### 2. 每 5 年大事件 + 技能獎勵
標準賽事外，每 5 回合一次大事件，獎金更高，贏家獲得技能。
- **解決什麼**：30 回合節奏平淡，沒有 milestone
- **代價**：命中 Frozen「四級聯賽 / 賽季結構」（30 回合本身就是賽季）；技能 = 新屬性層
- **解凍前要看**：Stage A 的均值回歸是否已修好「平淡感」；如已修好 → 可能不需要

### 3. 五行屬性（水火木）+ 遺傳 + Course 加成
每匹馬有屬性，從父母按機率繼承；跑特定 course 加成屬性。
- **解決什麼**：增加重玩變數、配對策略
- **代價**：全新屬性層 + 跟遺傳/賽事/育種三系統耦合 → Frozen 反模式正中
- **解凍前要看**：Run #3+ 玩家是否抱怨「策略深度不夠」

### 4. Course 屬性 + 地形偏好
不同 course 有屬性 + 偏好（速度/力量/體力 之一），影響賽事計算。
- **解決什麼**：賽事不再是純三圍總和，馬的「型」開始有意義
- **代價**：新 course 系統；跟 #3 強耦合（拆開做價值 50%）
- **解凍前要看**：Run #2-3 玩家是否會主動配「適合 course 的馬」

### 5. 突變給技能（從 #2 衍生）
突變時除了 +20 stat，還有極小機率給特殊技能。
- **解決什麼**：讓「下一胎極品」更興奮
- **代價**：技能 = 新屬性層（同 #2）
- **解凍前要看**：Stage A 紅字突變視覺是否已經夠「！」

## 解凍流程

1. Run #N 後寫 `playtest_notes.md`
2. 連續 3 場主動「再開一局」 = 好玩 → 砍掉本清單
3. 不好玩 → 從本清單挑 **1 條**（不要 2 條） → 開新 branch → 實作 → Run #N+1 → 判斷
4. 若解凍後仍不好玩 → 還原該條 + 砍掉

## 永久不解凍

- 卡牌系統（CLAUDE.md Frozen #1）— 跟交配/賽事三系統耦合
- 馬舍升級 / 設施經濟（Frozen #2）— 多一層金幣 sink 會掩蓋核心經濟
- 美術 / 音效 / 動畫 juice（Frozen #4）— 純文字 UI 是 iteration speed 命脈
