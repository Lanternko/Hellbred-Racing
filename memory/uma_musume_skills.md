# 賽馬娘技能參考（Hellbred 解凍時用）

> **狀態**：純參考文件。Hellbred MVP 期技能系統 Frozen，這份是未來解凍後設計地獄賽馬技能體系的素材庫，**不要在 MVP 期把這些技能塞進 `index.html`**。
> **來源**：賽馬娘 プリティーダービー（Cygames）日版主流版本，效果會隨版本微調。
> **整理日期**：2026-04-26

## 為什麼留這份

- 驗證「**條件觸發技能 + 三圍**」是賽馬娘讓「育成深度」成立的關鍵：~70% 技能依賴位置 / 距離 / 對手 / 賽道條件，讓三圍相同的兩匹馬因技能組合產生差異化結局。
- 這個結構可以直接對應 Hellbred 的「基因提純 → 血統繼承率」框架（金/綠/紫/固有 四階稀有度 ↔ 顯性 / 隱性遺傳）。
- 效果 90% 收斂在 **加速 / 回氣 / 視野 / 減益** 四類，不要做異質效果（護盾、瞬移、復活）—— 對應 CLAUDE.md `Frozen systems` 精神，避免賽事 simulation 爆炸。

## 解凍時的設計題（先想清楚再寫 code）

1. **觸發判定**：「終盤直線」「中盤前方有對手」這類條件需要賽事 simulation 有「位置 / 距離進度 / 相對排名」三個 tick-level 狀態。Hellbred 目前賽事是一次性結算，加技能 = 改成 tick-based。
2. **稀有度 vs 繼承**：金技能的繼承率比綠技能低，這個 mapping 要綁基因提純的「顯性 / 隱性」邏輯，不能各做一套。
3. **減益技能的對稱性**：紫技能會讓 AI 對手變強（因為對手用紫對你），玩家若沒有 counter 機制（如「ノンストップガール」反混亂）會挫敗 → 地獄賽馬要不要做減益要先想清楚。
4. **固有技能 vs 育成數量**：賽馬娘每個 trainee 一個固有技能，Hellbred 是純血統繼承沒有「角色」概念 → 固有技能要綁「血統」（如「魔王血脈」「炎駒血脈」）而不是個體。

## 解凍條件（同 CLAUDE.md `Frozen systems`）

- 自己連玩 ≥ 5 場 30 回合
- ≥ 3 場主動「再開一局」
- 至少 1 個朋友玩 1 場後不靠講解能知道下一步該做什麼
- 解凍時：在本檔結尾追加「解凍決策紀錄」（哪幾條 playtest 結論支持加技能、加哪幾類）
