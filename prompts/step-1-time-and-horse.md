# Step 1 — 時間軸 + 馬匹物件

**先決條件：** 無（這是第一步）。
**完成驗收：** `open index.html` 能看到「下一個千年」按鈕、按下後年份 +1000、馬匹年齡 +1、5 歲被移除；馬匹列表顯示性別（公 / 母）。

---

你現在是一個資深的遊戲系統工程師。我要開發一款名為《地獄賽馬》的純文字 Web 遊戲。請幫我用 HTML + JavaScript 寫出核心架構,並開啟 Artifacts 讓我可以直接遊玩。

**核心邏輯需求:**
1. **時間系統:** 遊戲總長 30 回合(顯示為 30,000 年)。提供一個「進入下一個千年」的按鈕。
2. **馬匹物件 (Class/Object):** 每匹馬有以下屬性:名字、性別(出生時隨機 50/50 分配「公」或「母」,終身不變)、年齡(初始為 0)、數值(速度、力量、體力,範圍 1-100)、狀態(0歲為「幼駒」,1-3歲為「巔峰」,4歲為「退役」,5歲死亡刪除)。
3. **介面顯示:** 畫面上需顯示當前年份、玩家資金(初始 1000G),以及玩家目前擁有的馬匹列表(顯示牠們的性別、數值與狀態)。
4. **回合推進運算:** 按下「下一個千年」後,所有擁有的馬匹年齡 +1,狀態自動更新。如果達到 5 歲則從列表中移除。

請給出極簡、現代感、深色主題的 UI 即可,重點在於邏輯正確無誤。
